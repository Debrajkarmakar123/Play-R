04 Game Build
HOW TO PUBLISH YOUR GAME

Your game must be available online before you submit it. Follow these simple steps:

  1. Create a GitHub account if you don't already have one.
  2. Create a new Public GitHub repository for your game.
  3. Upload all your game files to the repository.
  4. Your game must have an index.html file that starts the game.
  5. Go to your repository's Settings → Pages.
  6. Select Deploy from a branch.
  7. Select the main branch and / (root), then click Save.
  8. Wait for GitHub Pages to publish your game.
  9. Open the generated website URL and make sure your game works correctly.
  10. Copy that live website URL and paste it into the Live Game URL field below.
Example Live Game URL:
https://yourusername.github.io/your-game/

Important: Do not submit only the GitHub repository URL as the playable game link. PLAYR needs the live GitHub Pages URL to open and play your game.

Example: https://github.com/username/my-game
