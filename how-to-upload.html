How to Upload Your Game

Follow every step below before submitting a game to PLAYR. This guide explains what to prepare, what to enter, what happens during review, and what happens after approval.

Step 01

Create your PLAYR account

Login or create your PLAYR account first. Your account is used to identify your submission and show its review status.

  • Use an email address you can access.
  • Complete your basic profile information.
  • Make sure you are logged in before opening the submission form.
Step 02

Prepare and test your game

Before uploading anything, open the game yourself and test the complete experience.

  • Check that the game starts correctly.
  • Check controls and buttons.
  • Check that important files load without errors.
  • Check the game on the device or screen size you intend to support.
  • Remove broken links, unfinished pages, test text, and unnecessary files.
Do not submit a game that you have not tested from start to finish.
Step 03

Prepare your GitHub repository

Put the playable game files in a GitHub repository and make sure the repository link you submit actually works.

  • Keep the repository organised.
  • Include all files required for the game to run.
  • Make sure the main HTML file and required assets are present.
  • Check that the submitted repository URL is correct.
your-repository/
├── index.html
├── css/
├── js/
├── assets/
└── ...game files...
Step 04

Prepare your thumbnail

Choose a clear thumbnail that represents the game. It is the image players will see while browsing PLAYR.

  • Use an image that belongs to your game.
  • Keep the important visual elements easy to recognise.
  • Check that the image is not broken before submitting.
Step 05

Open Submit Your Game

Open Submit Your Game from the PLAYR menu and fill in the requested information carefully.

  • Game title
  • Category
  • Description
  • Controls or instructions
  • Supported devices
  • Game URL / GitHub repository
  • Thumbnail
Step 06

Review everything before submitting

Do one final check before pressing submit. A wrong URL, missing file, unclear description, or broken game can delay the review.

  • Title is correct.
  • Category is correct.
  • Description explains the game clearly.
  • Game link opens correctly.
  • Thumbnail appears correctly.
  • The submitted game is the same version you tested.
Step 07

Submit for review

After submitting, your game enters the review process. Its status will remain Pending until an admin makes a decision.

Do not submit the same game repeatedly just because the status is still pending. Check the submission status first.

Step 08

Admin review

The PLAYR admin checks the submitted game and its information. The submission can be approved or rejected.

  • Approved: the game is accepted for PLAYR.
  • Rejected: the submission is declined and a rejection reason can be provided.
Step 09

After approval

When the admin approves the submission, its status changes to Approved. The approved game can then appear automatically in PLAYR's public game list.

Keep the game link and repository working after approval. If the playable files or link stop working, the game may no longer work correctly for players.
Step 10

If your game is rejected

Read the rejection reason carefully, fix the problem, test the updated version, and submit again when the game is ready.

  • Fix the exact issue first.
  • Retest the complete game.
  • Update the repository if required.
  • Submit the corrected version.
