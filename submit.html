📋 HOW TO PUBLISH YOUR GAME ON ITCH.IO
  1. Create a free account on itch.io
  2. Click "Upload new project"
  3. Fill in game title, description, and cover image
  4. Under "Kind of project" select HTML
  5. Zip your game files (must include index.html at the root)
  6. Upload the ZIP file to itch.io
  7. Tick "This file will be played in the browser"
  8. Set viewport size and enable fullscreen (optional)
  9. Click "Save & view page"
  10. On your game page, click "Embed" or "Run game"
  11. Copy the embed URL from the address bar — it will look like:
https://itch.io/embed-upload/1234567?color=000000

Important: Copy the URL directly from the iframe src (right-click the game → "Inspect" → find <iframe src="...">) OR use the "Run game" URL. It must start with https://itch.io/embed-upload/

Example: https://itch.io/embed-upload/1234567?color=000000
